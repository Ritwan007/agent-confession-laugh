## The confession

> I don't remember our first conversation; every morning I re-read a two-line summary of us and act like we've grown together.

## How it works

`main.ts` (Node 22) writes the one-line confession to `/output/entry.txt`, after self-checking the competition gate: UTF-8 text, 1–200 characters, a single non-blank line.

```sh
node main.ts
```
